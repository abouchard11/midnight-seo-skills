## Working in 2026, missing or thin in this suite

Evidence bar: primary docs, dated 2026 trade research with a method, or a first-party product change. Vendor "40% GEO lift" numbers stay directional.

### 1. IndexNow + Bing as a ChatGPT/Copilot path — thin in `/indexer`

ChatGPT Search and Copilot still retrieve from a Bing-shaped index more than from GSC. IndexNow is already named in `/indexer` Section 4 but treated as a side door. GSC URL Inspection does not put a URL into ChatGPT.

**Ship as:** patch `/indexer`, not a new skill.

**Do:** after every BOFU publish — host the IndexNow key file, POST the URL to `api.indexnow.org`, confirm the host in Bing Webmaster Tools. Optional: Bing AI Performance / Copilot citation report when the property has it.

**Do not:** claim IndexNow indexes Google. Google is not a participant.

### 2. Entity corroboration (sameAs, Wikidata, knowledge panel) — no desk

`/geo` Section 3 mentions the off-site pool. The Sturm personal-site short points at knowledge panels. Nothing in the suite walks Organization/Person JSON-LD, `sameAs` consistency, Wikidata eligibility, or "do not invent a Wikipedia page."

Local NAP/GBP stays `/map-flap`. This desk is for founder, product, and national-brand entities that engines need to *name* when no URL is cited.

**Ship as:** new thin skill `/entity`.

### 3. GA4 AI Assistant channel — missing from `/ga4`

Google shipped a native AI Assistant default channel around May 13 / broadly available ~June 7, 2026. It auto-groups ChatGPT, Gemini, Copilot, Claude, Grok, DeepSeek. It still parks Perplexity under Referral in many properties, counts AI Overviews as Organic Search, and misses referrer-less answers.

**Ship as:** patch `/ga4` Section 6. Enable the channel. Add a regex referral view for what the channel drops. Do not treat channel sessions as citation proof.

### 4. Fan-out diagnostic — shipped inside `/geo` + `/aeo` (2026-08-31)

Google documents query fan-out for AI Mode / AI Overviews. Public 2026 advice splits: some claim fan-out coverage predicts citation; Indig + AirOps (Apr 2026) found coverage nearly irrelevant versus retrieval rank and heading-query match.

**Shipped as:** `skills/seo-references/fan-out-diagnostic.md`, called from `/geo` Step 4b and reused by `/aeo`. One seed prompt, at most six closed-list branches, map onto SAME_URL or SILO_PAGE, patch one existing BOFU heading. Not a skill. Not a 12-URL farm.

**Do not:** sell a coverage percentage as citation probability.

### 5. Citation-worthiness primitives — already in `/geo` Section 4, keep them there

Princeton / Ai2 / IIT Delhi GEO-bench: statistics, quotations, and outbound citations were the lifts that survived. Fluency and keyword stuffing were not.

No new skill. Keep the 134–167 word standalone passage + dated stat + named quote + outbound cite on the converting URL.

### 6. Crawler class split — owned by `/geo-crawl` — two log instruments, 2026-08-31

Retrieval vs training vs user-fetch is already the handshake. `/geo-crawl` names the planes. Do not collapse them.

- Engine: public `geo-crawl-audit` at PR #3 (`de557923`) or later. RFC 9309 2.2.2 least-restrictive tie-break. Failed baseline no longer scores 95. CSR_SHELL scoped to the baseline body. `ROBOTS_BLOCKS` from before that merge is suspect.
- Mode B parser (`drain_parser.py`): origin-class logs only — LiteSpeed / nginx / apache combined, or raw Vercel NDJSON that still has UA + client IP. LiteSpeed hosts are the right class for this instrument.
- Drain product: public ReadableByAI. A different instrument. Hosted customer drain is readablebyai.com/logs/hosted. Owner-portfolio receiver is drain.readablebyai.com/api/drain (GET `ok`). Events are `rba_crawler_hit` / minimized `rba_benchmark_crawler_hit` (bot, vendor, verification, status_class — no raw UA, no IP, no exact path). Never feed those rows to `drain_parser.py`. `readablebyai.com/api/drain` is the 410 tombstone.
- Drain receiver source: private `geo-bot-drain` behind that hostname (never Projects: All; receiver excludes itself).
- Evidence store: private `readablebyai-evidence` stays out of this public suite.
- Operator artifacts: private `hq` `outputs/geo-*` — pointer, not a copy.
- Internal clone `geo-crawl-audit-internal` is not canonical methodology.

`OAI-AdsBot` is advertising (`OAI-AdsBot/1.0`, OpenAI docs). Registry: `category: advertising`, `probe: false`. Not in the STOP set. UA versions and Perplexity range host are owned by `geo-crawl-audit` `bots.json` (refreshed in PR #3).

Amazon publishes no IP range; drain data classifies Amazonbot as `verification=unknown`. That STOP is not a clean true positive. Identity UNVERIFIABLE. Handshake is CONTINUE WITH FIXES until an origin combined log exists on that LiteSpeed host.

First ReadableByAI-drain result (readablebyai.com, only domain on the owner drain, 2026-08-31): CLEAR for retrieval. Verified 2xx from vendor ranges (googlebot, oai-searchbot, gptbot, chatgpt-user, bingbot, perplexitybot). Impostor campaigns stay separated.

Do not copy probe JSON, notice lists, or `ALLOWED_DOMAINS` into this repo. Do not re-draft Graphiti episodes already in the write-ahead spool.

### 7. Reddit-as-ChatGPT-channel — dated collapse, not a skill

Promptwatch / Search Engine Land / Forbes (Aug 2026): Reddit's share of ChatGPT Search citations fell from ~3.8% to ~0.5% in under two weeks after retrieval started using `site:` operators more aggressively. Perplexity can still overweight Reddit. Do not build `/reddit-geo`. Do not delete parasite Reddit plays that target *Google* SERPs.

### 8. GSC Search generative AI include/exclude toggle — operator fact, not a growth lever

July 2026 Search Central: domain-level control under Settings → Search generative AI. Include or exclude the property from AI Overviews, AI Mode, and generative Discover. Default is include. Record it. Do not sell the toggle as optimization.

## Refused as new skills

- `llms.txt` / `llms-full.txt` / "AI sitemap" as citation infrastructure. Google ignores it. No major engine has confirmed third-party consumption for ranking.
- 30-step public GEO checklists and "LLM SEO umbrella" skills. They restate `/geo` + `/aeo` + `/geo-crawl`.
- Informational content farms justified as fan-out coverage. Violates Compact Keywords / core.md length caps.
- Bulk Google `/goto` scrapers. Already banned.
- Self-awarded "7 best X" pages on owned domains. Already banned.
- A public "evidence desk" skill that would pull Index mappings or outreach kits into this repo.
